# 포근마을 🌼

키보드만으로 즐기는 작고 포근한 3D 마을 산책 게임입니다. (Three.js)

## 실행
- `index.html` 을 브라우저로 열면 바로 실행돼요. (인터넷 연결 필요 — Three.js와 폰트를 CDN에서 불러옵니다)
- 또는 로컬 서버: `python3 -m http.server` 후 http://localhost:8000

## 조작
| 키 | 동작 |
|---|---|
| `W A S D` / 방향키 | 걷기 (카메라 방향 기준) |
| `Shift` | 달리기 |
| `Q` / `R` | 카메라 회전 |
| `C` | 시점 초기화 |
| `E` / `Enter` | 말 걸기 · 이용하기 |
| `Space` | 점프 (낚시·미니게임·메뉴 안에서는 선택/당기기) |
| `B` | 자전거 타기/내리기 (대여소에서 빌린 뒤) |
| `G` | 곤충·물고기 도감 |
| `K` | 친구 수첩 (호감도) |
| `N` / 지도 클릭 | 큰 지도 (`←` `→` 로 다른 섬 지도) |
| `P` | 사진 모드 |
| `F` | 내 집 안에서 가구 배치 (방향키 옮기기 · `Q`/`R` 돌리기 · `Tab` 다음 가구 · `P` 넣기/꺼내기) |
| `Esc` | 닫기 · 그만두기 · (걷는 중엔) 메뉴 열기 |
| `H` | 도움말 |
| `M` | 소리 켜기/끄기 |

## 마을 구경
- ⛲ **마을 광장** — 분수와 벤치, 📮 **우체통** (친구들의 부탁 편지 → 들어주면 코인 보답)
- 🎆 **불꽃 호숫가 (북쪽)** — 데크에 앉으면 밤이 되고 불꽃축제가 시작돼요 (계절 상관없이)
- 🍢 **먹자골목 (동쪽)** — 떡볶이, 붕어빵, 솜사탕, 팥빙수. 포장해서 친구에게 선물할 수도 있어요
- 😴 **낮잠 언덕 (서쪽)** — 해먹 낮잠으로 기운 회복, 시간이 흘러요 (낮 → 노을 → 밤)
- 🛍️ **포근 잡화점 (북동쪽)** — 모자, 리본, 왕관, 선글라스, 풍선, 양산
- 🎣 **바닷가 선착장 (남쪽)** — 찌가 들어가면 `Space`, 초록 칸에서 한 번 더 `Space`! 10종의 물고기
- 🌻 **해바라기 미로 (북서쪽)** — 미로 깊숙이 숨은 🍉 수박 찾기
- ♨️ **포근 온천 (남서쪽)** — 카피바라와 함께 온천욕, 기운이 빠르게 차요
- 🎠 **축제 놀이터 (남동쪽)** — 회전목마, 🐠 금붕어 뜨기, 🎯 코르크 사격 (경품 아이템!)
- 🏠 **내 집** — 침대에서 자기, 옷장에서 갈아입기, 가구 카탈로그로 방 꾸미기
- 🚲 **자전거 대여소** — 빌려서 마을을 달리고, 점프대에서 붕~ 빌린 다음 날까지 반납해야 하고, 그 뒤로는 하루마다 연체료 🪙3이 빠져나가요
- 🌧️ **날씨** — 가끔 소나기가 내리고 (겨울엔 눈), 그친 뒤엔 무지개가 떠요
- 🐞 **곤충 채집** — 9종. 살금살금 걸어서 다가가야 잡혀요 (달리거나 자전거면 도망가요)
- 🗓️ **사계절 & 계절 축제** — 하루(밤→아침)가 3번 지나면 계절이 바뀌어요. 나무·땅·날씨·곤충이 달라지고,
  🌸 봄 벚꽃 축제 · 🌻 여름 축제 · 🍁 가을 수확 축제 · ⛄ 겨울 눈꽃 축제가 열려요.
  마을에 떠 있는 계절 토큰(🌸🐚🍁❄️)을 모아 광장 옆 부스에서 한정 모자와 가구로 바꿔요. 겨울엔 눈사람도 만들 수 있어요.
- 💗 **친구 호감도** — 마을 친구 5명(모모·콩이·보리·솜이·두부)과 하루 한 번 이야기, 선물, 부탁 들어주기, 함께 산책하기로 하트를 모아요.
  친구마다 좋아하는 것과 싫어하는 것이 있어요. 하트 2개면 좋아하는 것을 알려 주고, 3개면 같이 산책할 수 있고, 5개면 단짝이 돼요 (💗 단짝 하트 스티커)
- 🏡 **친구 집 놀러 가기** — 하트 1개 이상 친해지면 친구 집 문이 열려요. 친구마다 꾸민 방(캣타워, 부엌, 책장, 화장대, 수박 빈백)이 다르고,
  처음 놀러 가거나 함께 차를 마시면 호감도가 올라요
- 🚤 **다른 섬 4곳** — 남쪽 선착장 옆 통통배를 타고 가요
  - 🌴 **야자수섬**: 코코넛 줍기, 바위에서 코코넛 깨서 주스 만들기, 매일 새로 쌓는 모래성, 🏐 비치볼 통통 튕기기 미니게임, 해변 의자에서 쉬기, 코코의 주스 가게
  - 🍄 **버섯숲섬**: 밤에 빛나는 거대 버섯, 버섯 따기, 큰 솥에 버섯 수프 끓이기, 🌀 통통 버섯 트램펄린(공중의 반짝 포자 잡기), 부엉 할머니네
  - 🔭 **별빛섬**: 천문대에서 별자리 8개 찾기, 🌠 언덕 벤치에서 별똥별에 소원 빌기 (밤마다 3번)
    - 🎁 별빛 기념품 가게 (하늘섬 꾸미기 기념품 8종, 반짝 우주 헬멧), 🚀 하늘섬행 우주선
  - 🍓 **딸기섬**: 딸기 따기, 🐮 젖소 음매에게서 우유 짜기, 딸기 잼 · 딸기 우유 · 🍰 딸기 케이크 만들기, 풍차
    - 🧺 딸기 바구니 받기 미니게임, 🍰 딸기 카페 (딸기 탕후루 · 딸기 파르페)
- ☁️ **하늘섬** — 별빛섬 우주선을 타야만 갈 수 있는, 구름 위에 떠 있는 섬이에요. 카운트다운 → 발사 → 구름 속 → 착륙 장면이 나와요.
  별빛섬 기념품 가게에서 산 별 조각상, 초승달 램프, 토성 장식, 구름 소파, 미니 로켓, 별빛 풍경, 은하수 나무, 작은 망원경을
  안내판(또는 `F`)에서 원하는 자리에 놓고 돌리며 꾸밀 수 있어요 (밤에는 반짝반짝 빛나요)
  하늘섬 활동: 🐑 구름 양 몽글이 털 깎기(구름 솜), 🍭 구름 솜사탕 만들기, 🪁 바람 길을 따라 연날리기 미니게임
- 🧺 **섬 특산물 가게 (포근섬 선착장 앞)** — 다른 섬에서 모은 코코넛 · 버섯 · 딸기 · 우유 · 잼 · 케이크를 섬보다 비싸게 팔 수 있어요 (모두 팔기 지원)
- 🗓️ 화면 왼쪽 위에 코인과 함께 지금 계절 축제 토큰 개수(예: 🍁 단풍잎)가 보여요
- 🛋️ **가구 자유 배치** — 내 집에서 `F` 또는 카탈로그의 "가구 배치하기"로 가구를 원하는 곳에 옮기고 돌려요

## GitHub Pages로 배포하기
1. 저장소 **Settings → Pages** 로 이동
2. **Build and deployment → Source** 를 **Deploy from a branch** 로 선택
3. **Branch** 를 `main` / `/ (root)` 로 고르고 **Save**
4. 1~2분 뒤 `https://<사용자이름>.github.io/<저장소이름>/` 에서 플레이할 수 있어요

## 하루 생활 🕐
- **시계**: 마을 시간은 저절로 흘러요 (현실 1초 = 마을 1.5분, 하루 약 16분). 아침 6시가 되면 새로운 하루가 시작돼요.
  낮잠·침대로 시간을 건너뛸 수 있어요.
- **⭐ 레벨**: 낚시, 곤충, 부탁, 할 일, 아르바이트, 수확, 미니게임 등 활동할 때마다 경험치가 쌓여요. 레벨이 오르면 축하 코인과 함께
  🍅/🌽/🎃 씨앗, 🔨 집 넓히기, 아르바이트 하루 3번이 열려요.
- **📋 오늘의 할 일**: 광장 게시판에 매일 3개. 하나마다 🪙12 · 15XP, 모두 끝내면 보너스 🪙20 · 25XP
- **📮 우체통 부탁**: 하루에 한 통만 받을 수 있어요
- **🧑‍🍳 아르바이트**: 먹자골목 입구. 손님이 말한 음식의 숫자 키(1~4)를 눌러 내주면 한 명에 🪙3 + 팁. 시간이 갈수록 바빠지고, 2~3개 묶음 주문(순서대로!)·👑 VIP 손님이 나와요. 틀리면 처음부터 다시 + 팁 -1, 화난 손님 3명이면 그날 알바 끝 (하루 2번, Lv.5부터 3번)
- **🌱 내 텃밭**: 내 집 옆 6칸. 씨앗을 심고 매일 물을 주면 하루에 한 단계씩 자라요. 수확물은 특산물 가게에서 팔아요
- **🏠 월세 · 🔨 집 넓히기**: 5일마다 아침에 월세가 나가요 (🪙25 → 45 → 70). 카탈로그에서 집을 넓힐 수 있어요 (Lv.3 · 🪙250 / Lv.6 · 🪙600)
- **🎂 친구 생일**: 생일날엔 고깔모자를 써요. 생일 선물은 호감도가 두 배 + 답례 🪙15 (생일은 친구 수첩 K에서 확인)
- **📸 사진 모드 (P)**: 화면 장식을 숨기고 카메라를 돌려 `Space`로 찍으면 PNG로 저장돼요

## 코인 벌기 🪙

- 🧑‍🍳 아르바이트, 📋 오늘의 할 일, 🌱 텃밭 수확, 🎣 낚시, 🍓🥥🍄☁️ 섬 특산물 팔기 (만들어 팔면 더 비싸요)
- 📮 우체통 부탁, 🎠🏐🧺🪁 미니게임, 🏰 모래성, 🌠 별똥별 소원, 📖 도감 첫 발견, 💗 친구 레벨 보상, ⭐ 레벨 업 보상

진행 상황(코인, 아이템, 가구, 도감, 부탁, 호감도)은 브라우저에 자동으로 저장됩니다.

## 다른 기기에서 이어 하기 💾
1. 원래 기기에서 `Esc` → **저장 코드 만들기**를 누르면 코드가 클립보드에 복사돼요.
2. 코드를 메신저나 메모로 다른 기기에 옮겨요.
3. 다른 기기에서 `Esc` → **저장 코드 불러오기**를 고르고 코드를 붙여 넣은 뒤 `Enter`를 두 번 누르면 이어서 할 수 있어요.

서버 없이 동작해요. 코드에는 게임 진행 상황만 들어 있고 개인 정보는 없어요.

## 개발
게임 코드는 `src/` 폴더에 기능별로 나뉘어 있고, `index.html` 은 빌드로 만들어집니다.
(`index.html` 을 더블클릭으로 열어도 동작하도록 스크립트를 한 파일에 인라인으로 넣어요.)

```bash
node build.mjs
```

- `src/template.html` — HTML 뼈대
- `src/01-core.js` ~ `src/20-places.js` — 렌더러, 지형, 캐릭터, 기존 장소
- `src/00-hooks.js` — 장소 파일들이 모드·이름표·미니맵 아이콘 등을 등록하는 확장 포인트
- `src/30-fishing.js` ~ `src/54-photo.js` — 낚시, 해바라기 미로, 온천, 축제, 내 집(가구 배치), 자전거, 날씨, 곤충, 우체통, 사계절, 친구 호감도, 저장 코드, 다른 섬들, 하늘섬, 시계·레벨·할 일·아르바이트·텃밭·월세·생일·사진
- `src/80-nature.js` ~ `src/90-loop.js` — 나무·NPC, 플레이어·사운드, UI·입력, 친구 집(85), 메인 루프

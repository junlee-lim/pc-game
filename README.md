# 포근마을 🌼

키보드만으로 즐기는 작고 포근한 3D 마을 산책 게임입니다. (Three.js)

## 실행
- `index.html` 을 브라우저로 열면 바로 실행돼요. (인터넷 연결 필요 — Three.js와 폰트를 CDN에서 불러옵니다)
- 또는 로컬 서버: `python3 -m http.server` 후 http://localhost:8000

## 조작
| 키 | 동작 |
|---|---|
| `W A S D` / 방향키 | 걷기 |
| `Shift` | 달리기 |
| `Q` / `R` | 카메라 회전 |
| `C` | 시점 초기화 |
| `E` / `Space` / `Enter` | 말 걸기 · 이용하기 |
| `Esc` | 닫기 · 그만두기 |
| `H` | 도움말 |
| `M` | 소리 켜기/끄기 |

## 마을 구경
- ⛲ **마을 광장** — 분수와 벤치가 있는 마을 한가운데
- 🎆 **불꽃 호숫가 (북쪽)** — 데크에 앉으면 밤이 되고 여름밤 불꽃축제가 시작돼요 (하트·별·링·버들 불꽃)
- 🍢 **먹자골목 (동쪽)** — 떡볶이, 붕어빵, 솜사탕, 팥빙수 포장마차
- 😴 **낮잠 언덕 (서쪽)** — 해먹에서 낮잠을 자면 기운이 차고 시간이 흘러요 (낮 → 노을 → 밤)
- 🛍️ **포근 잡화점 (북동쪽)** — 밀짚모자, 리본, 왕관, 선글라스, 하트 풍선 등 꾸미기 아이템

마을 곳곳의 반짝이는 🪙 코인을 모아 음식과 아이템을 사세요. 마을 친구들에게 말을 걸 수도 있어요.
진행 상황(코인, 산 아이템)은 브라우저에 저장됩니다.
